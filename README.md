# Casa Nostra 🍝

Website moderno e responsivo desenvolvido para um restaurante italiano fictício, com foco numa apresentação elegante, navegação simples e sistema de reservas através do WhatsApp.

## 🌐 Demo

https://casa-ita-pt.netlify.app

## ✨ Funcionalidades

- Página inicial com apresentação do restaurante
- Menu com pratos e preços
- Secção sobre o restaurante
- Horários de funcionamento
- Formulário de reserva
- Envio automático da reserva através do WhatsApp
- Contactos
- Botão flutuante de WhatsApp
- Menu responsivo para dispositivos móveis
- Design adaptado a computador, tablet e telemóvel
- Navegação suave entre secções

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Netlify

## 📱 Responsivo

O website foi desenvolvido para funcionar corretamente em diferentes tamanhos de ecrã, incluindo computador, tablet e smartphone.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido como parte do meu portfólio, com o objetivo de criar uma solução moderna e funcional para restaurantes e pequenos negócios que pretendam melhorar a sua presença online e facilitar o contacto com os seus clientes.
